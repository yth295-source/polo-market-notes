# Polo’s market notes

**Polo 的市场解读** — 用数据形成判断，用新证据修正观点。

个人美国宏观与市场研究笔记，关注未来 1–6 个月的通胀、Fed、利率、盈利、估值与风险信号。

部署地址以 GitHub Settings → Pages 的成功状态为准。

## 内容

- 总览：主情景、预警、市场计价证据及验证日历。
- 传导链：通胀 → Fed → 利率 → 股票，附来源与反证条件。
- 研究预测：宏观工作判断及三类指数的条件估值，区分已知数据与主观假设。
- 金融检验：已封存的开发样本结果、误报、漏报、提前量与限制。
- 正式前瞻实验：固定规则和首期数据准备时间，与日常研究预测分开。

## 日期与限制

本仓库是**发布快照**，不是实时行情或数据服务。主要现况数据及复核为 2026-10-18 版本，研究预测 v4 签发于 2026-10-19；每个指标另列观察日期。10 月实验输入准备说明更新于 2026-10-21。这次公开发布没有重新核验金融数据，也没有重跑历史检验。

本地每天两次采集不代表网页每天更新。只有实际发布的内容会进入本网站；观点签发日、证据日期和预测期限不会因为上线或换名自动改变。

标普原精确单点目标已撤销，目前保留条件盈利与估值区间。Nasdaq-100 与 Nasdaq Composite 的旧情景尚未完成与标普同等深度的盈利重建。已看过的历史属于开发证据，尚未证明个股广度具有增量预测价值。

## 来源与发布范围

来源链接、观察日期和核验日期见网页“指标与来源”。本仓库仅包含个人研究文字、必要的引用快照、模型假设和汇总研究结果。原始 Sharadar 文件、逐股价格、完整成分股表、私有采集与判断账本、API 密钥和浏览器凭证不在本仓库。

第三方数据、商标及材料仍受原提供方条款约束，本仓库不为它们授予再分发许可。公开访问不代表开放数据授权。来源条款说明见 [DATA-SOURCES.md](DATA-SOURCES.md)。

## 运行与发布

这是无构建依赖的 HTML/CSS/JavaScript 静态网站，使用 hash 导航和相对资源路径。

本地：`python3 -m http.server 4174 --bind 127.0.0.1`

GitHub Pages：Settings → Pages → Deploy from a branch → `main` → `/ (root)`。保留 `.nojekyll`。

仅发布本目录的文件，不把完整研究工作区、下载目录或其 Git 历史推送到本仓库。

`final-qa.json` 是原 2026-10-18 的封存 QA，内部文件哈希对应当时版本；本次发布迁移的范围与校验另见 `release.json`，不改写原 QA。
